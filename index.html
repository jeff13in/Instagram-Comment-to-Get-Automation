Frequently Asked Questions

Is this compliant with Instagram's API policies?

Yes! We use the official Instagram Graph API v21.0 with proper OAuth authentication. All features comply with Meta's Platform Terms and API guidelines.

How fast are the responses?

In webhook mode, responses are sent within seconds. In polling mode, comments are checked every 60 seconds to respect API rate limits.

Can I customize the responses?

Absolutely! You can set custom reply messages, DM templates, and configure multiple keyword-response pairs. Supports dynamic variables like username.

What if I exceed my comment limit?

The bot will continue monitoring but won't send responses until the next billing cycle. You can upgrade your plan anytime for higher limits.

Do you store my Instagram credentials?

No. We only store the OAuth access token (encrypted) which has limited permissions. You can revoke access anytime from your Instagram settings.

Can I use this for multiple accounts?

Yes, depending on your plan. Professional supports 3 accounts and Enterprise supports unlimited accounts.
