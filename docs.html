Complete guide to setting up and using the 3p99 Instagram Comment-Bot automation system

Overview

The 3p99 Instagram Comment-Bot is an automated engagement system that monitors your Instagram posts, detects keyword triggers in comments, and responds automatically with customized messages and direct messages.

Built on the official Instagram Graph API v21.0, the bot operates in two modes:

  • Polling Mode: Checks for new comments every 60 seconds
  • Webhook Mode: Receives real-time notifications from Instagram

Quick Start

Get your bot running in 5 minutes:

1. Clone the Repository

git clone https://github.com/yourusername/3p99.git cd 3p99

2. Install Dependencies

pip install -r requirements.txt

3. Configure Environment

cp .env.example .env # Edit .env with your Instagram credentials

4. Run the Bot

python instagram_auto_responder.py

Note: Make sure you have a Facebook Developer account and Instagram Business account before proceeding.

Installation

Prerequisites

  • Python 3.8 or higher
  • Instagram Business or Creator account
  • Facebook Developer account
  • Meta App with Instagram permissions

System Requirements

Python >= 3.8 Flask >= 3.0.0 SQLAlchemy >= 2.0.23 requests >= 2.31.0

Install from Requirements

pip install -r requirements.txt

Authentication

OAuth 2.0 Flow

The bot uses Instagram's OAuth 2.0 for authentication. Follow these steps:

  1. Create a Meta App at developers.facebook.com
  2. Add Instagram product to your app
  3. Configure OAuth redirect URIs
  4. Request necessary permissions

Required Scopes

  • instagram_business_basic - Read basic account info
  • instagram_business_manage_comments - Read and reply to comments
  • instagram_business_manage_messages - Send direct messages
  • instagram_business_content_publish - Access post data

Getting Access Token

Run the authentication helper:

python sample_app.py

This will generate an authorization URL. Follow the prompts to obtain your long-lived access token.

Security: Never commit your access token to version control. Always use environment variables.

Keywords Setup

Configure trigger keywords in jeffin_config.json:

{ "app_id": "your_app_id", "app_secret": "your_app_secret", "access_token": "your_long_lived_token", "trigger_keywords": ["giveaway", "cyber", "books"], "comment_reply": "Thanks for your interest! 🎉", "dm_message": "Check your inbox for details!" }

Keyword Matching

The bot uses case-insensitive matching. A comment like "I love this GIVEAWAY!" will match the keyword "giveaway".

Message Templates

Customize your automated responses:

Comment Reply Template

"comment_reply_message": "Thanks for participating! Check your DMs 💬"

Direct Message Template

"dm_message": "Hi! Thanks for your interest. Here are the details..."

Tip: Use emojis and personalized language to increase engagement rates.

Operating Modes

Polling Mode (Recommended for Testing)

Checks Instagram API every 60 seconds for new comments:

from instagram_auto_responder import InstagramAutoResponder bot = InstagramAutoResponder('jeffin_config.json') bot.monitor_and_respond() # Runs continuously

Webhook Mode (Production)

Receives real-time events from Instagram:

python app.py # Start Flask webhook server

Configure webhook in Meta App settings:

  • Callback URL: https://yourdomain.com/webhook
  • Verify Token: Set in .env
  • Subscribe to: comments, messages

API Endpoints

Email Subscription

POST /api/subscribe

Subscribe email addresses from landing page.

POST /api/subscribe Content-Type: application/json { "email": "user@example.com" }

Get Subscribers

GET /api/subscribers

Retrieve all email subscribers (admin only).

Webhook Endpoint

GET/POST /webhook

Instagram webhook verification and event receiver.

Webhooks

Instagram webhooks provide real-time notifications for:

  • New comments on your posts
  • Direct message events
  • Mention notifications

Webhook Verification

Instagram sends a GET request to verify your webhook:

GET /webhook?hub.mode=subscribe&hub.challenge=123456&hub.verify_token=YOUR_TOKEN

Webhook Events

Example comment event payload:

{ "entry": [{ "id": "instagram_account_id", "changes": [{ "field": "comments", "value": { "id": "comment_id", "text": "I love this giveaway!", "from": { "id": "user_id", "username": "user_123" }, "media": { "id": "media_id" } } }] }] }

Rate Limits

Instagram Graph API enforces the following rate limits:

  • Standard tier: 200 calls per hour per user
  • Business tier: Higher limits available
  • Webhook events: No rate limit on receiving

Important: The bot automatically respects rate limits by checking comments every 60 seconds in polling mode.

Best Practices

  • Use webhook mode for production (no API calls needed)
  • Set polling interval to 60+ seconds
  • Implement exponential backoff on errors
  • Cache processed comment IDs to avoid duplicates

Deployment

Deploy to Railway

  1. Connect your GitHub repository to Railway
  2. Add environment variables from .env
  3. Railway will auto-deploy using Procfile

Deploy to Heroku

heroku create your-app-name heroku config:set INSTAGRAM_ACCESS_TOKEN=your_token git push heroku main

Environment Variables

Required for production:

INSTAGRAM_ACCESS_TOKEN=your_long_lived_token INSTAGRAM_APP_SECRET=your_app_secret VERIFY_TOKEN=your_webhook_verify_token DATABASE_URL=your_database_url

Database Setup

The bot uses SQLAlchemy for database operations. Supports SQLite (development) and PostgreSQL (production).

Automatic Setup

Database tables are created automatically when you run the app:

python app.py # Creates tables on first run

Database Models

  • EmailSubscriber: Stores landing page email signups
  • ProcessedComments: Tracks which comments have been responded to (future)

Troubleshooting

Common Issues

Access Token Expired

Symptom: Bot stops working after 60 days

Solution: Long-lived tokens expire after 60 days. Re-run sample_app.py to get a new token.

Webhook Verification Failed

Symptom: Instagram can't verify your webhook

Solution: Ensure your VERIFY_TOKEN matches in both Meta App settings and .env

Comments Not Being Detected

Symptom: Bot doesn't respond to comments

Solutions:

  • Check that keywords match (case-insensitive)
  • Verify you have Instagram Business/Creator account
  • Ensure proper permissions in Meta App
  • Check bot is running without errors

Rate Limit Errors

Symptom: API returns 429 errors

Solution: Increase polling interval to 120+ seconds or switch to webhook mode

Debug Mode

Enable debug logging:

DEBUG=True python app.py
